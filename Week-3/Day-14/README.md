# Enterprise Analytics Hackathon

## Overview

This project analyzes the **Microsoft AdventureWorks** database using **PostgreSQL** to solve real-world business problems through SQL Business Intelligence techniques.

The project demonstrates how an enterprise-scale relational database can be transformed into meaningful business insights using reusable SQL analytics pipelines and executive reporting.

---

## About AdventureWorks

AdventureWorks is Microsoft's official sample enterprise database that simulates the operations of a multinational manufacturing and retail company.

It contains realistic business data spread across multiple interconnected schemas, making it one of the most widely used databases for learning and demonstrating:

- Enterprise SQL Development
- Business Intelligence (BI)
- Data Analytics
- Database Design
- Reporting and Dashboard Development
- SQL Performance Optimization

The database models several business domains, including:

- Human Resources
- Sales
- Purchasing
- Production
- Person
- Finance

Because of its complexity and realistic relationships, AdventureWorks is commonly used in universities, technical interviews, data analytics bootcamps, and enterprise SQL training.
