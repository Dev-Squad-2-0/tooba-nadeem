# Advanced SQL Queries

## Overview

This project focuses on advanced SQL techniques using the PostgreSQL DVD Rental database. The queries demonstrate how to solve analytical business problems using aggregation, subqueries, Common Table Expressions (CTEs), and window functions.

## When to Use What?

### Subqueries

A subquery is a query written inside another query. It is useful when the result of one query is needed to filter, compare, or calculate values in another query.

**Use a subquery when:**
- Comparing values with an aggregate (average, maximum, minimum, etc.)
- Filtering data based on another query
- Checking whether records exist using `EXISTS` or `NOT EXISTS`
- Finding records that satisfy a calculated condition

**Examples from this project:**
- Customers who spent more than the average customer.
- Customers who have never rented a film.
- Store with the highest total revenue.

---

### Common Table Expressions (CTEs)

A Common Table Expression (CTE) is a temporary named result set created using the `WITH` keyword. It makes complex queries easier to read by breaking them into smaller logical steps.

**Use a CTE when:**
- A query becomes difficult to read.
- Intermediate calculations need to be reused.
- Building analytical reports with multiple steps.
- Replacing deeply nested subqueries with more readable SQL.

**Examples from this project:**
- Ranking customers after calculating total spending.
- Monthly revenue analysis.
- Ranking the highest-grossing films within each category.

---

### Window Functions

Window functions perform calculations across related rows without combining them into a single row like `GROUP BY`.

Unlike aggregate functions, window functions preserve every row while adding calculated information such as rankings, row numbers, running totals, or previous values.

**Use window functions when:**
- Ranking records.
- Finding the first or latest record in each group.
- Comparing values between consecutive rows.
- Performing analytical calculations while keeping all rows.

**Examples from this project:**
- `ROW_NUMBER()` to find each customer's latest rental.
- `RANK()` to rank customers and films.
- `LAG()` to compare monthly revenue with the previous month.

# How Each Business Question Was Solved

## Part 1 – Aggregation

### 1. Total revenue generated per store
Joined the `payment`, `rental`, and `inventory` tables and used `SUM(amount)` grouped by store to calculate total revenue.

### 2. Average rental duration per film category
Joined the `film`, `film_category`, and `category` tables and calculated the average rental duration for each category using `AVG()`.

### 3. Number of rentals made each month
Extracted the month from `rental_date` using `EXTRACT()` and counted rentals for each month.

### 4. Categories with more than 50 films
Grouped films by category, counted the number of films, and filtered the results using the `HAVING` clause.

---

## Part 2 – Subqueries

### 5. Customers who spent more than the average customer
Calculated total spending for each customer and compared it against the average customer spending using nested subqueries.

### 6. Highest rental-rate film(s) in each category
Used a correlated subquery to compare each film's rental rate with the maximum rental rate within its category.

### 7. Customers who have never rented a film
Used `NOT EXISTS` to identify customers who do not appear in the `rental` table.

### 8. Store with the highest total revenue
Calculated revenue for each store and used a subquery to return the store with the maximum revenue.

---

## Part 3 – CTEs & Window Functions

### 9. Rank customers by total spend within each city
A CTE calculated each customer's total spending. `RANK()` was then used to rank customers separately within each city.

### 10. Find the most recently rented film for each customer
`ROW_NUMBER()` partitioned rentals by customer and ordered them by rental date in descending order. The latest rental was selected where the row number equals 1.

### 11. Calculate month-over-month rental revenue growth
A CTE calculated monthly revenue. The `LAG()` window function retrieved the previous month's revenue, allowing the monthly growth percentage to be calculated.

### 12. Find the top three highest-grossing films per category
A CTE calculated total revenue generated by each film. `RANK()` ranked films within each category, and only the top three films from each category were returned.

# Business Insights

1. **Rental revenue grew rapidly during the first months of the year.** Revenue increased by approximately **186% from February to March**, followed by an additional **19.56% increase from March to April**, indicating a strong upward trend before declining sharply in May.

2. **The highest-grossing films vary across categories.** Every category has different top-performing films, showing that customer preferences differ by genre and that revenue is distributed across multiple categories rather than being dominated by a single film.

3. **Each store's revenue was generated entirely by its assigned staff member.** Store 1 generated **30,252.12** in revenue through Mike Hillyer, while Store 2 generated **31,059.92** through Jon Stephens. Since each store has one staff member processing payments in this dataset, each contributed **100%** of their store's revenue.
