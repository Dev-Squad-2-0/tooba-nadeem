# AFL Player Performance Investigation

## Overview

This project analyzes AFL player performance using player information, seasonal statistics, and round-by-round match data. The objective is to identify the most valuable and consistent players, analyze performance trends, evaluate team performance, engineer new performance metrics, and provide data-driven recruitment recommendations.

## Datasets

- `players_info.csv`
- `players_seasonal_stats.csv`
- `afl_players_round_by_round_stats_raw.csv`
- `merged_players.csv`
- `cleaned_round_by_round_stats.csv`

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Workflow

1. Loaded and inspected the datasets.
2. Performed data cleaning and quality validation.
3. Created a custom Performance Index using five key performance metrics.
4. Ranked the top 10 most valuable players.
5. Identified the most consistent players using fantasy point variation.
6. Analyzed player improvement and decline throughout the season.
7. Ranked teams based on overall player performance.
8. Engineered five new performance-related features.
9. Generated visualizations and business insights.
10. Recommended five players for recruitment based on the analysis.

## Outputs

- `day8_AFL_Analysis.ipynb`
- 8 visualizations
- 10 business insights
- Final recruitment recommendations
