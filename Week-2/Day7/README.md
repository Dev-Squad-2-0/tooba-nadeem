# Day 7 – Exploratory Data Analysis (EDA) on AFL Dataset

## Objective
Perform Exploratory Data Analysis (EDA) on the cleaned and merged AFL player dataset to identify trends, patterns, and key insights using Pandas, Matplotlib, and Seaborn.

## Tasks Completed
- Analyzed total player-games by team.
- Visualized the distribution of player ages (`last_age`).
- Identified player team combinations with the highest number of players.
- Compared player weight across different teams.
- Found teams with the highest average fantasy points.
- Identified the Top 15 goal scorers.
- Analyzed the number of records available for each season.

## Visualizations Used
- Horizontal Bar Chart
- Histogram
- Boxplot
- Vertical Bar Chart
- Line Chart

## Tools & Libraries
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Files
- `EDA_AFL.ipynb` – Notebook containing the complete analysis.
- Exported chart images (`.png`)
- `merged_players.csv` – Cleaned and merged dataset used for analysis.

## Key Learning Outcomes
- Performed exploratory data analysis using Pandas.
- Selected appropriate chart types based on business questions.
- Interpreted visualizations with observations and business insights.
- Summarized findings into actionable insights.
